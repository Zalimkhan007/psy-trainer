# Тренажёр по психологии

Тесты к дифференцированному зачёту по психологии: уровень 1 (149 вопросов, один ответ) и уровень 2 (150, несколько ответов).
Одна страница, работает в браузере без сервера, прогресс хранится в браузере.

Сборка: `python build.py` — вшивает `data/*.json` в `template.html` → `index.html`.
